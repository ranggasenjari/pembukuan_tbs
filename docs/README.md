# Project Docs

Folder ini menyimpan dokumentasi dan artefak referensi yang berkaitan langsung dengan project.

- `CHANGES_SUMMARY.md`: ringkasan perubahan besar.
- `DEVELOPMENT_SETUP.md`: panduan setup development.
- `MODULES.md`: catatan modul/fitur.
- `OCR_MISTRAL_API.md`: catatan integrasi OCR Mistral.
- `SECURITY.md` dan `SECURITY_CHANGES.md`: catatan keamanan.
- `api/`: spesifikasi API eksternal atau referensi vendor.
- `database/`: SQL pendukung/schema manual.
- `artifacts/`: artefak referensi yang tidak menjadi source aplikasi.

Dokumentasi khusus Express tetap berada di `app_express/docs/`.
